# 项目说明

## 各文件夹使用说明

| 文件名   | 描述                 |
| -------- | -------------------- |
| Arts     | 放置项目中的美术资源 |
| Audios   | 放置项目中的音效文件 |
| Docs     | 放置策划案文档       |
| Models   | 放置 3D 模型文件     |
| Previews | 游戏效果预览图       |

## 文件命名规则

仅仅 Arts 和 Audios 文件有命名规则
命名规则以 **文件类型\_文件名\_文件索引** 起名
文件类型需要 **大写**
文件名中每一个单词首字母 **大写**

### 文件类型

| 文件类型 | 简称           |
| -------- | -------------- |
| 图片     | **P**(Picture) |
| 音效     | **S**(Sound)   |

### 文件索引

文件索引用于当某一个文件名用于多个文件的时候, 用文件索引来标注当前文件是第几个文件, 例如:

```text

只有一个文件的情况:
P_Door
P_Table
S_BackgroundMusic

有多个同名文件的情况:
P_Door_0
P_Door_1

P_Table_0
P_Table_1
P_Table_2

S_BackgroundMusic_0
S_BackgroundMusic_1
```
